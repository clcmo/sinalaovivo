Política de Privacidade

Última atualização: 16 de agosto de 2026

O Sinal Ao Vivo (dev.camilaloliveira.me) é uma aplicação web focada na agregação e organização de transmissões ao vivo públicas do YouTube. Esta Política de Privacidade descreve como as suas informações são tratadas ao utilizar a plataforma.

1. Informações Coletadas e Como São Utilizadas

• Dados de Autenticação Google: Quando você opta por entrar com sua conta Google, utilizamos o protocolo OAuth 2.0 apenas para identificar o seu perfil (nome, e-mail e foto de perfil) e autenticar requisições de leitura na API do YouTube.

• Dados de Canais Favoritos e Preferências: Os canais que você marca como favoritos e as preferências de tema são armazenados exclusivamente no seu navegador via localStorage.

• Chave de API (Uso Opcional): Se você optar por inserir manualmente uma chave da API do YouTube, ela permanecerá salva apenas no seu navegador.

2. Integração com a API do YouTube

O Sinal Ao Vivo utiliza os Serviços de API do YouTube (YouTube API Services). Ao utilizar este site, você concorda em estar vinculado aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

Solicitamos estritamente a permissão de leitura https://www.googleapis.com/auth/youtube.readonly. Não modificamos, criamos ou apagamos dados na sua conta do YouTube. O acesso é estritamente limitado à consulta e exibição de transmissões ao vivo públicas.

3. Armazenamento e Retenção de Dados

Não mantemos um banco de dados externo ou servidor próprio para guardar suas informações pessoais. Todos os dados de sessão e preferências residem localmente no seu dispositivo.

4. Compartilhamento e Venda de Dados

Nenhum dado pessoal ou de uso é vendido, alugado, transferido ou compartilhado com terceiros ou redes de publicidade.

5. Controle e Exclusão de Dados pelo Usuário

Você pode apagar todos os seus dados salvos a qualquer momento utilizando o botão "Apagar meus dados salvos neste navegador" dentro da aplicação, ou limpando os dados de navegação do seu navegador. Para revogar o acesso do app à sua conta Google, acesse as Configurações de Segurança da sua Conta Google.
