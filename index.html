SINALAO VIVO

Canais do YouTube transmitindo agora, organizados por segmento. Entre para salvar seus favoritos.

1. Identificação

Sem senha e sem cadastro — esse nome só identifica onde ficam guardados sua chave de API e seus canais favoritos neste navegador.

2. Conectar API

A chave fica salva só no seu perfil, neste navegador — nunca é enviada a nenhum servidor além do Google. Para criar uma, acesse console.cloud.google.com/apis/credentials e ative a "YouTube Data API v3". Cada busca consome cota da API (~100 unidades por segmento).
